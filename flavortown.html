To provide some context, Zipline has 3 roles for the users:

  • USER: A normal user with no admin privileges, it can just upload files, shorten URLs, view their files and stuff like that.
  • ADMIN: A user with admin privileges that can manage users and invites but not the instance settings. This role can not be given at registration as per API limitations.
  • SUPERADMIN: The owner of the instance, the only user who can also manage the instance settings. This user can only be created as the first user ever of the instance, only one SUPERADMIN account can exist on an instance.
